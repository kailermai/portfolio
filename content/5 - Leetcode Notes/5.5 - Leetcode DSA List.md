# Medium

| Problem                                                                                                   | Type                | Key Ideas                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| --------------------------------------------------------------------------------------------------------- | ------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [LRU Cache](https://leetcode.com/problems/lru-cache/description/)                                         | Design              | **Hashmap** for O(1) cache access, with key as the actual key and value being the node in the double ended linked list, Node(key, value)<br><br>**Double ended linked list** to store the least and most recently used node for O(1) get and put, using helper functions to reorder when node is used. Use a dummy node to point to the start and end.                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| [Coin Change](https://leetcode.com/problems/coin-change/description/)                                     | Dynamic Programming | **Bottom up DP**, base case where we want to sum to 0 is 0 coins<br><br>Initialise a DP array to store the number of coins needed for all cases to be infinity<br><br>Followed by calculating the number of coins needed to sum from 0 to target amount using memoisation and brute force recursion                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| [Jump Game](https://leetcode.com/problems/jump-game/description/)                                         | Dynamic Programming | **Brute force solution**: Without memoisation, time complexity is roughly n^n<br><br>**Greedy solution**: start with the final index (goal) and check if there is any preceding index that can reach it. If possible, then the new goal will be the index that can reach it for subsequent indices. If we reach the start of the array where the we can reach the goal then it is possible, otherwise impossible<br>TC: O(n)<br><br>**Dynamic Programming**: Use recursion to check every possible step from the first index and subsequent indices, and if the recursive call reaches the end, memoise the result to true, otherwise memoise the result to false<br>TC: O(n^2), SC: O(n)                                                                                                                         |
| [Number of Connected Components in a Undirected Graph](https://www.lintcode.com/problem/3651/)            | Graph               | **Union find disjoint set** to **union** 2 nodes if they have an edge connecting them, using a helper function to **find** the parent of the node<br><br>Initialise a parent and rank array, where parent tracks the node's parent by index (if the node is a parent of itself, then it is the root node), and the rank array to store the weight of the node (for tree balancing)<br><br>Find operation to find the parent of the node, using path compression as we iterate through the node's parent<br><br>Union operation to combine 2 nodes into a tree using the find operation, and ensure balancing of the trees using weights<br><br>For each successful union operation, subtract 1 from the number of nodes, and the result is the answer of how many disjoint sets<br><br>**Alternatively, use DFS** |
| [Combination Sum](https://leetcode.com/problems/combination-sum/description/)                             | Recursion           | **Backtracking** and creating a **copy of the array** to add to result<br><br>Recursion tree can either use the current ith value for subsequent recursive calls, or move on to the next value in the candidates                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| [Longest Palindromic Substring](https://leetcode.com/problems/longest-palindromic-substring/description/) | String              | **O(n^3) Solution**: For every substring (O(n^2) substrings), check if it is a palindrome by using 2 pointers, either starting from the centre until the middle, or middle and expand outwards (O(n) time)<br><br>**O(n^2) Solution**: Instead of checking for all substrings, we can iterate through the string and check for substrings using the current character as the center of the palindrome. Doing this will iterate through O(n) length of the string, and each check will take O(n) time                                                                                                                                                                                                                                                                                                              |
| [Pow(x, n)](https://leetcode.com/problems/powx-n/description/)                                            | Math                | **O(n) Solution**: While loop or recursion where the result is multiplied by x until n is 0<br><br>**O(log n) Solution**: Divide and conquer approach, eliminate repeated work by computing only half the power and taking the power of 2 of the result, and taking the reciprocal if needed                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
