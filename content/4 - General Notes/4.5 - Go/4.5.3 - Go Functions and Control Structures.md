## Throwing an error (exception)
```GO
import "errors"

func foo() (int, int, error) {
	var err error // defualt value is nil
	if ... {
		err = errors.New("ERROR!")
		return 0, 0, err
	}
}

// to handle error
if err != nil {
	fmt.Printf(err.Error())
}
```
## If else statements

- if, else if, else
- switch case - break is implied in each case

switch {
	case err != nil:
