Similar to arrays, but immutable and initialise with parentheses
We can only index them, but we cannot modify them
```python
tup = (1, 2, 3)
tup[1]
tup[1] = 0 # DOES NOT WORK
```

Tuples are mainly used as keys for a hashmap or hashset
```python 
mymap = { (1, 2): 3 }

myset = set()
myset.add((1, 2))
print((1, 2) in myset)
```
We use tuples because lists cannot be keys, they are not hashable
