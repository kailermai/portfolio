# NUSPlan (Orbital)
An all-in-one productivity android application designed for NUS students, to improve academic schedule management and boost student productivity. This project is developed under the CP2106 Independent Software Development Project, otherwise known as [Orbital](https://nusmods.com/courses/CP2106/independent-software-development-project-orbital).

> [NUSPlan - README](../2%20-%20Blogs/2.2%20-%20NUSPlan/NUSPlan%20-%20README.md)

>Built with Flutter/Dart, Firebase, Python FastAPI, Gemini API
