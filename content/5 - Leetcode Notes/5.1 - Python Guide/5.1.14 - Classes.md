self is similar to this keyword in Java

```python
class MyClass:
    # Constructor
    def __init__(self, nums):
        # Create instance fields
        self.nums = nums
        self.size = len(nums)
        
    # self keyword is required as a parameter for methods
    def getLength(self):
        return self.size
        
    # calling a member method from another method
    def getDoubleLength(self):
        return 2 * self.getLength()
```
