# Guide
- `.` => any except newline
- `\d` => any digit [0, 9]
- `\D` => any character that is NOT a digit
- `\s` => any whitespace character
- `\S` => any non-whitespace character
- `\w` => any word character, alphanumeric (a-z, A-Z and 0-9) and underscores (\_ )
- `\W` => any non-word character
- `X{n}` => n numbers of X, where X is any regex and n is the number of it
