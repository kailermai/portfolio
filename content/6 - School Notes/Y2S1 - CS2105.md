# Overview
## What is the Internet
- Network of connected computing devices (hosts/end systems)
	- Hosts run network applications that communicate over links/network, such as Zoom, browser, WhatsApp
## Network Edge (Access Network)
- Hosts access the internet through access network
	- Residential (home), institutional (campus), mobile (4G) etc
### Home network
![](content/assets/default/Pasted%20image%2020250810222045.png)
- Modem: connect home network to ISP network
- Router: set up home network => assign IP addresses to each device, network address translation, firewall service
### Enterprise Access Networks (Ethernet)
![](content/assets/default/Pasted%20image%2020250810222512.png)
- Used in companies, universities
- Transmission rates: 10 Megabit per second (MBPS), 100Mbps, 1Gbps and 10Gbps 
- Host typically connect to Ethernet switch
### Wireless Access Networks
- Connects hosts to router via base station (access point)
#### Wireless LANs
- within building (100 ft)
- 802.1.1 b/g/n/ac (Wi-Fi)
#### Wide-area wireless access
- 3G, 4G
- provided by telco (cellular) operator, 10's km
### Physical Media
- Hosts connect to access network over different physical media
#### Guided media
- Cable
- Signals propagate in solid media
	- Different types: error prone, transmission speed, prone to wear and tear
- Twisted pair cable, Fiber optic cable
#### Unguided media
- Over air (Wi-Fi)
- Signals propagate freely
## Network Core
- Mesh of interconnected routers
	- No users
	- Belong to big companies
- Routers: Specially-designed computers for forwarding data in a network
- How data is transmitted through network
	- Circuit switching: dedicated circuit per call
	- Packet switching: data sent through network in discrete chunks (packets)
### Circuit Switching
![](content/assets/default/Pasted%20image%2020250811001003.png)
- End-end resources allocated to and reserved for "call" between source and destination
	- Call setup required => delay depending on distance
	- **Guaranteed performance** (circuit-like) because circuit is reserved and no other users can use it
	- Circuit segment idle if not used by call (**no sharing**)
	- Commonly used in **traditional telephone network**
- In diagram, each link has four circuits, and a call gets 2nd circuit in top link and 1st circuit in right link
- If user > circuits, some users cannot reserve circuits and cannot use network and user is not served
### Packet Switching
- For internet
- Host sending function
	- Breaks application message into smaller chunks (packets) of length L bits
	- Transmits packets onto the link at transmission rate R
	- Receiver combine packets to restore original message
- **Link transmission rate** is link capacity or link bandwidth
![](content/assets/default/Pasted%20image%2020250811002242.png)
- **Packets**: contain multiple bits, and each bit is sent 1 by 1 sequentially as an EM wave (sine/cosine)
#### Store and forward
- Packets are passed from one router to another, across links on path from source to destination
- **Store and forward:** entire packet must arrive at a router before it can be transmitted on the next link
	- Leads to end to end delay, router needs to check if packet is correct (verify integrity), and drops the packet otherwise
