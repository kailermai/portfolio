# While loops

```python
n = 0
while n < 5:
	n += 1
```
# For loops
```python
# Looping from i = 0 to 4
for i in range(5):

# Looping from i = 2 to 5
for i in range(2, 6):

# Looping from i = 5 to 2
for i in range(5, 1, -1): # we can also decrement by 2 using -2 instead of -1
```
